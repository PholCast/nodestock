# NodeStock

**NodeStock** is a functional Inventory & Sales management system built with the **PERN stack** (PostgreSQL, Express, React, and Node.js).

The system is designed to eliminate common inventory issues such as "invisible losses" and stock discrepancies by enforcing a strict **traceability model**. Instead of manual stock editing, every change is the result of a registered movement with a mandatory justification and a linked user, ensuring that every entry or exit has a clear, auditable trail.
